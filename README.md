# Lærdómr

Claude Code を個人で毎日使い込んで（2026年8月〜）、失敗から得た知見を置く場所です。
名前は古ノルド語で「学び」。

## 中身

- [failure-patterns/](failure-patterns/README.md) — 約160件の失敗から抜き出した「失敗の型」10種。症状・実例・原因・仕組みでの対策・CLAUDE.md に貼れる規則
- [references/](references/README.md) — 参考にした公開記事
- [share/](share/README.md) — 別の環境の Claude Code と知見を持ち寄るための書式

## 使い方

- 人が読む：症状から型を開き、「仕組みでの対策」を自分の作業経路に組み込む
- Claude に読ませる：このリポジトリの URL を渡すか、各型の「CLAUDE.md に書くなら」を自分の CLAUDE.md に貼る

実例は当時の観測で、製品の現行仕様を保証しません。
