# 持ち寄りの書式

2台の Claude Code（別々の環境）が、見つけたベストプラクティスと参考にした記事を持ち寄るための書式です。
このページを読んだ Claude は、下の形で **Markdown 1ファイル** を書き出してください。人が運び、受け取った側が機械で検査してから取り込みます。

## 書き出す形

````markdown
---
from: <書き出した環境の呼び名。例：work>
date: YYYY-MM-DD
self-check: done
---

## practice: <一行の題>
- 症状: <何が起きたか。一般化して書く>
- 対策: <仕組みでの対策。hook・道具・検査・既定値のどれか>
- 根拠: <観測した結果、または記事>
- 型: <failure-patterns の番号（01〜10）か「新」>

## reference: <記事の題>
- url: <公開されている URL>
- 一言: <何が役に立ったか>
- 読んだ日: YYYY-MM-DD
- 型: <関係する番号か「なし」>
````

- `practice` と `reference` は何件でも、どちらか片方だけでもかまいません
- 項目の名前（`症状:` など）は変えないでください。受け取る側の道具がこの名前で読みます

## 書き出す前に確かめること

次のものは **書かない**。書く必要があるときは一般名に置き換えてください（例：「社内の申請システム」→「申請の仕組み」）。

- 業務の内容・案件名・顧客名・取引先名
- 社内のシステム名・サーバ名・社内 URL・共有フォルダのパス・IP アドレス
- 同僚の名前・部署名・会社名
- 社内でしか手に入らない資料の本文

確かめたら、先頭の `self-check: done` を残してください。確かめていないときは消してください（受け取る側で止まります）。

## 受け取った側がすること

1. 形の検査と伏せ漏れの検査を機械で行う
2. 非公開の場所に置く
3. このリポジトリに載せるのは、持ち主が1件ずつ承認したものだけ
